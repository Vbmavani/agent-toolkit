MCP, end to end

The Model Context Protocol (MCP) is an open standard for giving an AI app tools and data. A server offers tools, resources and prompts. A client, running inside a host app such as Claude Desktop or Claude Code, connects to the server and hands its tools to the model.

Everything here is connected: an 11-chapter course on how I learned MCP, a working weather server, a client that talks to it, a reference for every field in the spec, and background on who uses MCP. Start at the top and use Next at the bottom of each page.

The three building blocks

Server offersWho decides to use itIn the weather server
Tools: functions the model can callThe modelget-forecast, get-alerts, open-facebook-login
Resources: data the app can readThe appweather://alerts/{state}, weather://rotate/{states}
Prompts: templates the user picksThe userNone on main yet

The spec reference covers the rest: transports, capabilities, elicitation, subscriptions, tasks and authorization.

Run it yourself

Needs Node.js 24+. Clone agent-toolkit, then:

cd mcp/weather-server-typescript && npm install && npm run build
cd ../mcp-client-typescript && npm install && npm run build
cp .env.example .env   # add your ANTHROPIC_API_KEY
node build/index.js ../weather-server-typescript/build/index.js

Then ask "What's the weather in Sacramento?". Without an API key the client still connects and prints the server's tools, which is a quick way to check the wiring.
