MCP adoption in numbers

In October 2026 the two official MCP SDKs were downloaded — times, and — organisations with a verified domain published their first server to the official MCP Registry.

No public dataset counts "companies adopting MCP" directly. The closest public signal is the official registry: a publisher that proves it owns a domain (for example com.stripe) gets a reverse-DNS namespace, while individuals publish under io.github.<user>. Domain-verified namespaces are used here as the stand-in for companies. It is an upper bound: a solo developer with a personal domain counts too, and large companies that host servers only on their own sites never appear. Months run to 31 October 2026; November is left out because it has only just started.
